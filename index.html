Attention rollout

Residual-augmented attention matrices multiplied across encoder layers, read from the class token and upsampled to slice resolution. The three planes are shown separately because they are fused only at the embedding stage.

Regional analysis

The axial slice is divided into a 6×6 grid mapped to five coarse regions. Values are scaled relative to the peak region, so the top region sits near 1.0 and the rest are fractions of it. The spread is taken across five slice depths at 5% increments.

What this demo does and does not do

Attention rollout and the grid-based regional analysis are forward-only computations, so they port exactly. Grad-CAM and LIME do not, and are not included here:

  • Grad-CAM needs gradients with respect to patch tokens. Because the backbone is frozen and only the class token reaches the classification head, patch-token gradients are identically zero unless you backpropagate through the final encoder block. ONNX Runtime Web has no autograd, so this would mean a hand-written backward pass and a fresh source of disagreement with the published figures.
  • LIME fits its linear model over 1000 masking perturbations, which is 1000 forward passes. Single-threaded WebAssembly would take roughly ten minutes. Cutting to 200 perturbations would change the local fidelity away from the 0.78 reported in the paper.

Both are in the notebook in the main repository, which is the reproducible artifact for the paper. This page is a convenience for inspecting the model interactively.
